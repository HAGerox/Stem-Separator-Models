# Security policy

## Reporting a vulnerability

Do not include credentials, private audio, private filenames or other sensitive material in a public issue.

Use GitHub's private **Report a vulnerability** flow when it is available. If private vulnerability reporting is not enabled, contact the maintainer privately through the GitHub profile associated with this repository before sharing details.

## Scope

Security reports may cover the registry data, validation and PR-generation scripts, GitHub Actions workflows, or accidental disclosure of private evaluation material. Model weights and third-party runtimes are maintained upstream; report their vulnerabilities to their respective projects as well.
